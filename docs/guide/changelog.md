# 更新日志

## 🚀 v1.0.1 (2026-09-01)

### ✨ 新特性与功能优化
- **📲 独立版本更新模态弹窗 & 全生命周期支持**：
  - 更新弹窗重构为内置独立遮罩浮层，摆脱 Android Window Token 限制，确保在游戏闪屏页、验证页及游戏主界面均可 100% 稳定弹出；
  - 版本号分行清晰展示，采用精致副文本配色；
  - 默认更新弹窗标题与更新日志支持在 `SiyoX_Config.h`（`SIYOX_DEFAULT_UPDATE_TITLE` / `SIYOX_DEFAULT_UPDATE_LOG`）中集中自定义。
- **🔗 智能直链下载与应用内无缝安装**：
  - 自动识别下载链接类型（直链 vs 网页/网盘跳转）；
  - 直链触发应用内高速异步下载，配备横向圆角进度条与右侧实时百分比显示；
  - 下载完成后按钮无缝切换为「安装」，通过 Android `FileProvider` 自动安全调起系统安装器覆盖安装；
  - 非直链或网页外链自动唤起系统浏览器访问。
- **🔢 内部整数版本号与 Xposed 模块解耦**：
  - 彻底解耦宿主游戏 `PackageManager`，统一使用 `SiyoX_Config.h` 中的 `SIYOX_VERSION_CODE` 整数版本号进行网络验证与更新比对；
  - 外部显示版本号通过 AndroidManifest / Gradle 配置并由客户端动态展示。
- **🛡️ 免验证模式与面板状态升级**：
  - 验证模式重新规划为：`0=关闭验证 (免卡密模式)`、`1=EPIC (摇光云)`、`2=T3 验证`、`3=微验`；
  - 免验证模式下跳过卡密拦截界面，面板授权状态显示为「永久」，到期时间显示为「永久」。
- **⚡ Google R8 深度编译优化**：
  - 启用 R8 Tree Shaking 与二进制资源自动剪裁（Shrink Resources），精准保护 Xposed、JNI 与网络验证 SDK 符号；
  - APK 构建体积由 `5.78 MB` 缩减至 **`1.96 MB`（缩小 66.1%）**。
- **🖼️ 超清高清 Logo 资产升级**：
  - 文档站 Favicon、导航栏图标及客户端内置资源全量替换为超高清原图。
- **🌐 站点架构合并与自动化部署**：
  - 个人主页与 SiyoX 文档站合并至单一仓库托管，统一自动化构建与部署。

### 🐛 缺陷修复
- **修复微验有时提示 `null` 的问题**：
  - 增加多字段安全提取机制，全面防御 JSON 中的 `null` 字符串转换问题；
  - 底层 Native C 自动清洗 host 协议头，保证网络通信与错误提示 100% 准确。
- **修复闪屏页切换时弹窗可能丢失的问题**：
  - 全局缓存更新状态，Activity 切换时自动无缝衔接。

## 📦 v1.0.0 (2026-08-31)

### 🌟 初始版本发布
- **多网络验证集成**：原生对接 EPIC（摇光云）、T3 验证、微验（WeiYan）三大网络验证平台；
- **Native C++ 核心**：底层网络通信、RC4 / RSA 加解密与数据签名在 Native (JNI) 层执行；
- **资源包在线下载与注入**：支持预置多资源包直链高速下载、MD5 完整性校验与游戏私有目录自动解压注入；
- **全局集中化配置**：客户端信息、验证参数与资源列表统一由 `SiyoX_Config.h` 集中管理。
