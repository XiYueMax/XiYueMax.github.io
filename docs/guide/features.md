# 核心架构与特性

SiyoX 采用 C++ Native 底层与 Java 业务调度双层架构，兼顾执行性能与安全性。

---

## 🌟 核心特性详解

### 1. 多网络验证接入
内置深度对接主流三大网络验证平台：
- **EPIC（摇光云）**：基于 RSA 签名与通信包装；
- **T3 网络验证**：RC4 对称加密、HEX 编码通信与增强时间戳防重放；
- **微验（WeiYan）**：RC4-Hex 加解密与单码卡密授权体系。

### 2. Native C++ 核心底层
- 所有的网络数据封包、RC4 / RSA 加解密与签名校验均下沉至 C++ (JNI) 实现；
- Java 层仅负责界面交互与数据转发，有效防止核心业务逻辑被静态反编译。

### 3. 在线资源包拉取与注入
- 支持配置多个在线材质包直链；
- 内置 MD5 完整性校验机制，防止文件传输损坏或被中间人篡改；
- 下载完成后自动解压并释放至游戏私有目录。

### 4. 灵动岛（Dynamic Island）悬浮胶囊
- 游戏顶部实时悬浮胶囊，动态显示客户端名称、时间、作者及下载进度条；
- **半透明实时预览**：在设置弹窗中调节缩放、圆角弧度与屏幕双向偏移时，弹窗自动半透明，实时直观预览效果；
- **状态圆点取色板**：内置 ColorWheelView 色轮选择器，支持自由定制状态圆点颜色与透明度。

### 5. EntityKiller 实体与材质冲突清理
- 智能解决官方武器（剑/刀）、护甲、attachables 及渲染控制器对自定义材质包的覆盖冲突；
- 支持后台自动匹配并清除非法/冗余资源，并在功能面板提供一键手动触发清理。

### 6. 游戏内 HUD 增强（帧率与按键显示）
- **实时帧率显示 (FPS Display)**：游戏内独立浮层实时统计与展示渲染帧率，支持自由拖拽位置与参数重置；
- **按键回显与触发器 (Key Display & Trigger)**：实时响应并高亮触摸操作，配备屏幕虚拟按键映射与可视化布局调整。

### 7. 热更新绕过（UniFix Bypass）
- 在客户端启动阶段智能拦截 UniFix 动态热更新请求与远程探针；
- 有效阻断官方反作弊模块下发与热修复补丁注入。

### 8. 自定义启动视频与屏幕水印
- 支持游戏启动时自动下载并替换游戏内置登录背景视频；
- 屏幕右下角支持自定义质感文字水印展示。

### 9. 开发者调试模式
- 在“关于软件”面板连续点击 5 次版本号即可触发开启开发者模式；
- 提供灵动岛进度全动态模拟（0%~100%）、状态测试、更新弹窗测试等一站式调试工具。

### 10. 集中式配置管理
- 所有自定义参数（客户端信息、验证方式、密钥、接口 ID、资源包列表、EntityKiller 规则、视频及水印配置）全部汇聚在 `SiyoX_Config.h` 单一头文件中；
- 开发者修改配置无需改动任何 Java 源码。

### 11. 极致轻量与规范
- 剔除冗余依赖与构建缓存，全项目核心源码精简高效；
- 除主配置文件外，严格遵循 0 注释规范。
