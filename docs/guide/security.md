# 安全须知与加固建议

::: danger 1. 资源包无加密提醒
**SiyoX 本身并未对资源包进行二次加密。**

所有下载并注入的材质资源均会直接解压释放到《我的世界》私有存储目录中，用户可在设备的文件管理器中直接提取和查看。

**强烈建议：请勿使用本项目分发需要强版权保护或保密性的商业资源！**
:::

::: warning 2. 公开发布前的防护建议
若你计划将编译后的软件公开发布使用，在发布前**请务必进行以下加固防护措施**：
1. **源码混淆加密**：
   - 开启 ProGuard / R8 深度字典混淆规则；
   - 对 Java 业务层关键逻辑进行字符串与控制流混淆。
2. **Native 层代码保护**：
   - 对 C++ 中的敏感字符串进行异或/动态拼装隐藏；
   - 开启符号剥离（`strip`）。
3. **APK 软件加固**：
   - 使用第三方成熟加固方案进行整体加壳、防 Hook、防动态调试及 VMP 保护；
   - 严防网络验证通信逻辑被直接 Bypass 或资源包直链被爬取。
:::
