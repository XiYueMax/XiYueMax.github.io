# T3 网络验证配置

SiyoX 原生支持 T3 验证系统的 RC4 传输加密模式与 HEX 数据编码通信。

---

## 1. 客户端代码配置 (`SiyoX_Config.h`)

将 `SIYOX_ACTIVE_VERIFY_TYPE` 设为 `2`，并填写以下参数：

```c
#define SIYOX_ACTIVE_VERIFY_TYPE 2

#define SIYOX_T3_API_HOST        "http://w2.t3yanzheng.com"  // T3 接口域名
#define SIYOX_T3_APP_KEY         "your_t3_app_key"           // T3 应用 AppKey
#define SIYOX_T3_RC4_KEY         "your_t3_rc4_key"           // T3 RC4 传输加密密钥
#define SIYOX_T3_LOGIN_CODE      "your_t3_login_code"        // 单码卡密登录 调用码
#define SIYOX_T3_NOTICE_CODE     "your_t3_notice_code"       // 获取程序公告 调用码
#define SIYOX_T3_VERSION_CODE    "your_t3_version_code"      // 获取最新版本 调用码
#define SIYOX_T3_HEARTBEAT_CODE  "your_t3_heartbeat_code"    // 单码心跳验证 调用码
```

---

## 2. T3 管理后台必配项

为确保与 SiyoX 的底层加解密协议匹配，**必须**在 T3 管理后台中完成以下设置：

### ① 传输配置 ➔ 加密配置
- **全局数据加解密**：开启
- **加密算法**：选择 **`rc4`**
- **请求值加密**：开启
- **返回值加密**：开启
- **请求值编码**：选择 **`HEX编码（16进制）`**
- 点击 **保存配置**

### ② 效验配置
- **时间戳校验**：开启
- **时间戳校验增强**：开启

### ③ 返回值配置
- **格式选择**：**`JSON`**
- **JSON返回时间戳**：开启
- **JSON_CODE 类型**：选择 **`int`**
